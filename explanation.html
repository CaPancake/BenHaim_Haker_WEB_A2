1. CNN (Convolutional Neural Network)

A neural network designed for image recognition. It learns patterns such as edges, textures, and object shapes.

2. Convolution

The operation of applying filters to an image in order to detect visual patterns.

3. Filter (Kernel)

A small matrix that scans the image and extracts important visual features.

4. Feature Map

The output generated after a filter is applied to an image.

5. Pooling

A technique that reduces image dimensions while preserving important information.

6. Max Pooling

A pooling method that keeps only the largest value from a region.

7. ReLU

An activation function that replaces negative values with zero.

8. Neuron

A basic processing unit in a neural network.

9. Layer

A collection of neurons that process data together.

10. Input Layer

The first layer that receives image data.

11. Hidden Layer

Intermediate layers where feature extraction and learning occur.

12. Output Layer

The final layer that produces the prediction result.

13. Forward Pass

The process of passing data through the network to generate predictions.

14. Backpropagation

The learning process that updates weights based on prediction errors.

15. Weight

A learned parameter that determines the importance of an input.

16. Bias

An additional value that helps the network fit data better.

17. Epoch

One complete pass through the entire training dataset.

18. Batch

A small subset of training samples processed together.

19. Batch Size

The number of samples included in one batch.

20. Learning Rate

Controls how much the weights are updated during training.

21. Loss Function

Measures how far predictions are from the correct answers.

22. Accuracy

The percentage of correct predictions made by the model.

23. Training

The process of teaching the model using labeled examples.

24. Testing

Evaluating the model on unseen data.

25. Validation

Checking model performance during training to prevent overfitting.

26. Dataset

A collection of samples used for training and testing.

27. Label

The correct class assigned to a training sample.

28. Classification

The task of assigning an image to a category.

29. Prediction

The class selected by the trained model.

30. Overfitting

When the model memorizes training data and performs poorly on new data.

31. Underfitting

When the model fails to learn important patterns from the data.

32. Normalization

Scaling input values to a standard range for better learning.

33. Gradient

Indicates the direction and magnitude of weight updates.

34. Optimizer

An algorithm that updates weights during training.

35. Softmax

Converts outputs into probabilities for each class.

36. Activation Function

A function that introduces non-linearity into the network.

37. Hyperparameter

A setting chosen before training, such as learning rate or epochs.

38. Model

The complete neural network architecture and learned weights.

39. Local Storage

Browser storage used to save trained weights and settings.

40. Inference

The process of using a trained model to make predictions on new images.
